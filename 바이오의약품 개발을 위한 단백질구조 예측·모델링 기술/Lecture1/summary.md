아미노산 -> 펩타이드(20개보다 적은 아미노산이 모여서 구성) -> 단백질

protein structure modeling.
아미노산 서열 -> 3차원 단백질 구조

backbone에다가 서로다른 sidechain이 붙으므로서 서로다른 성질을 나타나게 된다.

물이 나오면서 아미노산 두개가 붙는 결합을 펩타이드 결합이라 한다.

N terminal -> C terminal 방향성이 있다.

2차 구조-> beta pleated sheet / alpha helix / coil(여집합)

-main chain(backbone) 끼리의 수소결합으로 alpha helix 형성
-beta sheet 형태는 anti parallel / parallel 구조 두 개 존재

3차 구조-> 2차구조의 배열이 결정함
